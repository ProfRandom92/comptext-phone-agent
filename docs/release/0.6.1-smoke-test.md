# CompText Phone Agent 0.6.1 First-User Smoke Test

This procedure is intentionally non-destructive. It uses repository fixtures and a sandbox rather than real phone storage, cloud credentials or personal files.

## 1. Clean installation

```bash
git clone https://github.com/ProfRandom92/comptext-phone-agent.git
cd comptext-phone-agent
git checkout docs/community-release-0.6.1
bash install-termux.sh --sandbox
```

Expected: installation completes without root, remote pipe-to-shell execution or secret prompts.

## 2. Doctor

```bash
./.venv/bin/comptext-phone doctor
```

Expected: Python, directories, configuration, database and optional integrations are reported clearly. Missing optional Android services must not be reported as fatal.

## 3. Create mock phone data

```bash
./.venv/bin/comptext-phone demo --path ./mock-phone
```

Expected: deterministic mock files are created only under `./mock-phone`.

## 4. Read-only scan

```bash
./.venv/bin/comptext-phone scan --path ./mock-phone --top 10
./.venv/bin/comptext-phone analyze large --path ./mock-phone
./.venv/bin/comptext-phone duplicates --path ./mock-phone --verify
```

Expected: analysis succeeds and no file is moved, renamed, overwritten, uploaded or deleted.

## 5. Generate a report

```bash
./.venv/bin/comptext-phone report --path ./mock-phone --format markdown
./.venv/bin/comptext-phone report --path ./mock-phone --format json
./.venv/bin/comptext-phone report --path ./mock-phone --format html
```

Expected: three report formats are generated; HTML contains no external CDN dependency.

## 6. Verify approval enforcement

```bash
./.venv/bin/comptext-phone cleanup plan --path ./mock-phone --old-days 0 --json
```

Record the returned plan ID. Attempting to apply it before approval must fail:

```bash
./.venv/bin/comptext-phone cleanup apply <PLAN_ID>
```

Expected: rejected because no valid approval exists.

## 7. Approve and apply reversible cleanup

```bash
./.venv/bin/comptext-phone cleanup approve <PLAN_ID> --phrase APPROVE
./.venv/bin/comptext-phone cleanup apply <PLAN_ID>
./.venv/bin/comptext-phone trash list
```

Expected: only planned, unprotected mock candidates move into the sandbox trash. The approval cannot be reused.

## 8. Restore

```bash
./.venv/bin/comptext-phone trash restore <ITEM_ID> --phrase APPROVE
```

Expected: the selected mock item is restored without overwriting an unrelated file.

## 9. Test suite

```bash
./.venv/bin/pytest
python scripts/preflight_source_audit.py
```

Expected: tests and source audit pass.

## 10. Data-preserving uninstall

```bash
bash uninstall.sh
```

Expected: executable installation is removed while configuration, approvals, audit history and trash metadata are preserved. Do not use `--purge-data` during this smoke test.

## Evidence to record

- operating system and Termux source/version;
- Python version;
- commit SHA;
- command exit codes;
- sanitized test summary;
- generated report filenames;
- confirmation that no real storage path or credential was used.
