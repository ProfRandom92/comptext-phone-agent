# CompText Phone Agent 0.6.1

CompText Phone Agent 0.6.1 is a release-candidate update for the local-first Android and Termux assistant. It combines storage analysis, reversible cleanup, audit evidence, the mobile TUI, bounded agent runtime, local orchestration and the optional authenticated loopback Android broker.

## Highlights

- Read-only storage analysis remains the default.
- Cleanup and backup operations use typed, hash-bound plans.
- Mutating actions require expiring, single-use approvals.
- Reversible cleanup moves files into `.CompTextTrash`.
- Reports are available as Markdown, JSON and self-contained HTML.
- The local orchestrator routes only to a fixed trusted action catalog.
- The optional Android broker accepts authenticated loopback communication only.
- Release packaging now includes stronger rollback verification and more portable CLI tests.

## Install

```bash
git clone https://github.com/ProfRandom92/comptext-phone-agent.git
cd comptext-phone-agent
bash install-termux.sh
export PATH="$HOME/.local/bin:$PATH"
comptext-phone doctor
```

Before using real storage, run the sandbox smoke test in [`0.6.1-smoke-test.md`](0.6.1-smoke-test.md).

## Upgrade

```bash
bash update.sh
comptext-phone doctor
```

Review local configuration changes before enabling controlled actions. Existing audit, approval and user-data directories are preserved.

## Security model

Model output cannot execute arbitrary shell commands. Supported actions pass through schema validation, runtime policy and approval checks. Protected paths, symlink escapes and changed plan parameters are rejected.

## Known limitations

- No root access or scoped-storage bypass.
- Some `Android/data` paths remain inaccessible.
- Long scans may be interrupted by Android power management.
- rclone credentials require deliberate manual configuration.
- The Android LiteRT-LM broker is optional and device compatibility varies.
- This version does not provide unrestricted screen control or autonomous destructive cleanup.

## Rollback and uninstall

```bash
bash uninstall.sh
```

Configuration, audit history, approvals and trash metadata are preserved by default. Full removal requires `bash uninstall.sh --purge-data` and the exact phrase `DELETE COMPTEXT DATA`.
