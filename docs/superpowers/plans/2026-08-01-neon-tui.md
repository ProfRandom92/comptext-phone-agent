# CompText Phone Agent 0.4 Neon TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a responsive, event-driven Neon TUI and strengthen local durable execution without adding a Temporal server dependency.

**Architecture:** Existing runtime events are reduced into immutable view state and rendered through a trusted Textual widget catalog. SQLite remains authoritative for history, runs, signals, and resume behavior.

**Tech Stack:** Python 3.12+, Textual, Rich, SQLite, pytest, existing CompText runtime.

## Global Constraints

- Keep Termux Python 3.14 support.
- Preserve `comptext-phone chat --simple`.
- No arbitrary model-generated UI or shell execution.
- No Temporal cluster on Android.
- All changing actions remain approval-bound.
